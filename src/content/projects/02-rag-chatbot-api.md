Implemented a Retrieval-Augmented Generation (RAG) chatbot API that allows users
to interact with product data. The chatbot generates responses based on
pre-calculated document embeddings and can answer queries related to product
specifications, user manuals, warranties, and installation guidelines.

This chatbot API integrates with a FastAPI backend, processing up to 5–6 PDFs per
product. It effectively handles embeddings to generate accurate, real-time
responses to customer queries using previously indexed product documents.

The solution improves customer support by providing precise and context-aware
answers to product-related questions.
